# 微积分复习笔记

本笔记用于检索评测，内容为一元微分学的基础概念。

## 导数的定义

导数的定义是差商的极限：若极限

lim(h→0) [f(x+h) - f(x)] / h

存在，就称 f 在 x 处可导，并把该极限记为 f'(x)。导数刻画的是函数在一点附近的瞬时变化率，
几何上对应曲线在该点处切线的斜率。

可导一定连续，连续不一定可导；绝对值函数在原点就是典型的反例。

## 链式法则

链式法则用于复合函数的求导：若 y = f(u) 且 u = g(x)，则

dy/dx = f'(u) · g'(x)。

它的直觉是"变化率沿链条相乘"：x 的变化先按 g 放大，再按 f 放大。
多层复合时可以反复套用，从最外层一路乘到最内层。

## 隐函数求导

当 y 由方程 F(x, y) = 0 隐式确定时，把 y 看作 x 的函数，方程两端同时对 x 求导，
再解出 dy/dx，这就是隐函数求导法。

求导时 y 的每一项都要乘上 dy/dx，这是最容易漏掉的一步。
圆的方程 x² + y² = r² 是标准例子：求导得到 2x + 2y·dy/dx = 0。
