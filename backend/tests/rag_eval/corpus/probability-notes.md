# 概率论复习笔记

本笔记用于检索评测，内容为概率论基础概念的整理。

## 条件概率

设 A、B 是两个事件，且 P(B) > 0，则称

P(A|B) = P(A∩B) / P(B)

为在事件 B 已经发生的条件下事件 A 发生的条件概率。

条件概率描述的是"已知 B 发生"这条信息对 A 发生可能性的修正。它本身仍然是一个概率，
满足非负性、规范性与可列可加性，因此概率的一切性质对它都成立。

要注意条件概率的样本空间已经被压缩到 B 内部：分母不再是 1，而是 P(B)。

## 全概率公式

若 B1, B2, ..., Bn 构成样本空间的一个划分，并且每个 P(Bi) > 0，则对任意事件 A 有

P(A) = P(B1)P(A|B1) + P(B2)P(A|B2) + ... + P(Bn)P(A|Bn)。

全概率公式的用途是把一个复杂事件 A 按原因分解成若干互斥的情形，分别计算以后再求和，
因此它常被当作"分类讨论"的严格写法。使用前必须先写清楚划分，且划分不能重叠、不能遗漏。

## 贝叶斯公式

在同样的划分下，对任意的 i 有

P(Bi|A) = P(Bi)P(A|Bi) / P(A)。

其中 P(Bi) 称为先验概率，表示观测之前对原因 Bi 的信念；P(Bi|A) 称为后验概率，
表示观测到结果 A 之后对同一个原因的信念。贝叶斯公式做的就是"从先验更新到后验"。

分母通常用全概率公式展开，所以两个公式经常配合使用。

## 常见错误

把 P(A|B) 与 P(B|A) 混为一谈是最典型的错误。两者一般并不相等，只有在特殊情形下才相同。
另一个常见错误是在使用全概率公式时忘记检查划分条件，导致重复计数或漏项。
