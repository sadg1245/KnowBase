# 线性代数复习笔记

本笔记用于检索评测，内容为矩阵与向量组的基础概念。

## 矩阵的秩

矩阵的秩等于它的行阶梯形中非零行的个数，也等于最高阶非零子式的阶数。

秩刻画的是矩阵所代表的线性映射的像空间维数，因此初等行变换不改变秩。
计算秩的常规做法是先用初等行变换化行阶梯形，再数非零行。

## 特征值与特征向量

若存在非零向量 x 与数 λ 使得 Ax = λx，则称 λ 是矩阵 A 的特征值，x 是对应的特征向量。

特征值的求法是把方程改写成 (A - λI)x = 0，由于特征向量非零，系数矩阵必须奇异，
所以特征值满足特征方程 det(A - λI) = 0。解这个方程得到全部特征值，再代回求特征向量。

## 向量组的线性无关

向量组 α1, α2, ..., αm 线性无关，指的是只有当系数 k1 = k2 = ... = km 全为零时，
线性组合 k1α1 + k2α2 + ... + kmαm 才等于零向量。

判断方法：把这些向量按列排成矩阵，做初等行变换求秩。秩等于向量个数就线性无关，
小于向量个数就线性相关，并且相关时非零行对应的向量构成极大线性无关组。
